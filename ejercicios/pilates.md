# Ejercicio Pilates

## Descripción
El Método Pilates es un conjunto de movimientos controlados para el cuerpo y la mente. Dichos movimientos y ejercicios también se realizan sobre colchonetas y máquinas de pilates diseñadas especialmente para una correcta ejecución. Joseph Pilates fue el creador de este innovador sistema de ejercicios de cuerpo y mente.
