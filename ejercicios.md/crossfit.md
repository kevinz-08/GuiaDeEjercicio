# Ejercicio CrossFit

## Descripción
El CrossFit es un sistema de entrenamiento de fuerza y acondicionamiento físico que combina ejercicios de diferentes disciplinas deportivas. Se caracteriza por ser de alta intensidad y por variar los movimientos de forma constante.

El CrossFit se basa en: 
Conectar movimientos de diferentes disciplinas, como la halterofilia, el entrenamiento metabólico o el gimnástico 
Realizar ejercicios funcionales, como levantamiento de pesas, correr, sentadillas, burpees o saltos 

Ejecutar los ejercicios a alta intensidad 
Estudiar el cuerpo humano bajo diferentes situaciones de estrés
